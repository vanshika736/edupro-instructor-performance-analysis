EDUPRO COMPLETE PROJECT

Run locally:
1. Install Python 3.10+.
2. Keep EduPro Online Platform.xlsx in the same folder as edupro_streamlit_app.py.
3. Run: pip install -r requirements_edupro.txt
4. Run: streamlit run edupro_streamlit_app.py
5. Or upload the workbook using the app sidebar.

Deliverables include Excel dashboard, detailed research report, executive summary, stakeholder presentation, Streamlit source and source dataset.

Method caution: transactions are used as enrollment proxies. CourseRating is course-level, not individual instructor-level. Correlation is descriptive, not causal.
